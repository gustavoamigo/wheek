# Wheek! Darling's Great Adventures

**Play it:** https://gustavoamigo.github.io/wheek/

A cosy, wordless exploration game for children aged 5–8. Runs in the browser.

```
python3 tools/serve.py 8765      # then open http://linuxpc.local:8765/
```
